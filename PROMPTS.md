# Week 7 – Prompt Engineering Log

## Prompt Version 1

### Prompt
Generate marketing content for the following food product.

### Example Input
Product Name: Mango Juice
Category: Juice
User Prompt: Generate Instagram caption

### Example Output
- Product Description
- Basic Instagram Caption
- A few hashtags

### Observation
The output was relevant but lacked promotional depth and branding.

## Prompt Version 2

### Prompt
Generate a professional marketing description, promotional content, Instagram caption, catchy tagline, and five hashtags for the following food product.

### Example Input
Product Name: Mango Juice
Category: Juice
User Prompt: Generate Instagram caption

### Example Output
- Detailed product description
- Promotional advertisement
- Better Instagram caption
- Marketing tagline
- Five hashtags

### Observation
The response was more structured and suitable for marketing purposes, but sometimes the tone was too generic.

---

## Prompt Version 3 (Final)

### System Role
You are an expert marketing content writer for food processing businesses.

### Prompt
Generate:
1. Product Description
2. Promotional Content
3. Social Media Caption
4. Marketing Tagline
5. Five Relevant Hashtags

### Example Input
Product Name: Mango Juice
Category: Juice
User Prompt: Generate Instagram caption

### Example Output
- Professional Product Description
- Promotional Content
- Social Media Caption
- Catchy Tagline
- Five Relevant Hashtags

### Why this Prompt was Selected

This prompt consistently produced well-structured marketing content with a professional tone. The addition of a system role helped the AI generate more relevant and creative responses tailored to food products. It also ensured that all required marketing components were included in a single response, making it the best prompt for this project.
