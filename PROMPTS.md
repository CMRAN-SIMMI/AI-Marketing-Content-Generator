# AI Marketing Content Generator – Prompt Log

## Prompt Version 1

### Prompt

Generate a marketing description for the given food product.

### Example Input

* Product Name: Mango Juice
* Category: Juice
* User Prompt: Generate Instagram caption

### Example Output

A simple marketing description and caption.

### Observation

The output was useful but lacked promotional details and branding.

## Prompt Version 2

### Prompt

Generate a professional marketing description, promotional content, social media caption, tagline, and five relevant hashtags for the given food product.

### Example Input

* Product Name: Mango Juice
* Category: Juice
* User Prompt: Generate Instagram caption

### Example Output

* Product Description
* Promotional Content
* Instagram Caption
* Marketing Tagline
* Five Hashtags

### Observation

The response was much more structured and useful for marketing.

## Prompt Version 3 (Final)

### System Prompt

You are an expert marketing content writer for food processing businesses.

### User Prompt

Generate:

1. Product Description
2. Promotional Content
3. Social Media Caption
4. Marketing Tagline
5. Five Relevant Hashtags

for the following product.

### Example Input

* Product Name: Mango Juice
* Category: Juice
* User Prompt: Generate Instagram caption

### Example Output

A complete marketing package including:

* Professional product description
* Promotional advertisement
* Social media caption
* Catchy tagline
* Relevant hashtags

### Why This Prompt Was Selected

This prompt produced the most structured and professional marketing content. It consistently generated all required marketing elements in a single response, making it suitable for social media promotion and digital marketing. The addition of a system prompt improved response quality and maintained a professional tone across different product categories.
